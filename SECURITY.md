# Security Policy

## Supported Versions

Only the latest commit on `main` is supported.

If a vulnerability also affects upstream Bevy, please report it to Bevy as well, via their
[Security Advisories](https://github.com/bevyengine/bevy/security/advisories/new) page.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please DO NOT disclose it publicly until we’ve had a chance to fix it.

Please don’t report security vulnerabilities via GitHub issues, instead [report them privately](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) via the [Security Advisories](https://github.com/titan-engine/titan/security/advisories/new) page.
