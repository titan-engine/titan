Keyboard required: WASD or arrow keys. Requires WebGPU or WebGL2 with floating-point color attachments.

Use a current browser with GPU support. The RPG and arena offer keyboard controls and on-screen movement buttons. If GPU play is unavailable, their paused inspectors provide software captures. The 3D collection room requires a compatible GPU and has no software fallback.

The games run in your browser. Inspection controls apply only to your own game session; they start read-only. Recordings and snapshots stay local unless you choose to share them.
