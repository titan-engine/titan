# Titan

Titan is a game engine being built in Rust for humans and AI agents to build games together. The goal is a visual editor for humans and a CLI that lets agents perform the same game-authoring tasks without automating the editor.

The project is just getting started. There is no engine, editor, or CLI to build or run yet. The first game will be a small, old-school 2D platformer, with macOS supported first, then Linux and Windows.

## Getting involved

Start with the [development constraints](docs/development.md) to understand the project’s direction and requirements. Work is planned in [GitHub issues](https://github.com/titan-engine/titan/issues) before implementation. Choose an issue with an agreed scope, and keep each pull request focused on one understandable change.
